## 🎯 What It Does

MeetIntel runs as a **desktop overlay alongside Google Meet** (or any meeting tool). It:

1. **Captures audio** from your system microphone in real-time
2. **Transcribes speech** using Deepgram Nova-2 with speaker diarization
3. **Identifies who said what** — maps speaker numbers to real names using Gemini
4. **Detects task assignments live** — when someone says *"Parth, please update the API docs by Friday"*, Parth's swimlane in the dashboard is instantly populated
5. **Generates a full meeting debrief** after the session ends, including summary, key decisions, risks, and action items
6. **Exports a PDF report** directly to your Downloads folder via Electron's native `printToPDF`

## ✨ Features

### 🎙️ Live Transcription
- Real-time speech-to-text via **Deepgram Nova-2** with multi-speaker diarization
- Speaker labels (`Speaker 1`, `Speaker 2`) are progressively resolved to real names
- Streaming interim results with final segment stitching

### 🤖 Participant-Aware Task Intelligence
- **Name-triggered detection**: fires immediately when a participant's name is spoken
- **Sliding window analysis**: every 3 final transcript segments also trigger a Gemini sweep
- Tasks are attributed to the correct person even before identity mapping completes
- Participant swimlanes with colour-coded cards showing priority, due date, and the exact quote

### 🏊 Swimlane Task Dashboard
| Person | Colour | Role |
|---|---|---|
| Aaditya Hingmire | Rose/Red | Admin / Manager |
| Parth Bhad | Violet | Team Member |
| Aryan Karpe | Cyan | Team Member |

- Tasks grouped by assignee in collapsible lanes
- Priority badges: 🔴 High · 🟡 Medium · 🟣 Low
- Mark complete, delete, filter (All / Pending / Done)

### 📋 Post-Session Debrief
- Executive summary, key decisions, risks, next steps
- Full action item log with assignee attribution
- Generated by **Gemini 1.5 Pro** on the complete transcript

### 📄 PDF Report Export
- Three-layer strategy — always works:
  1. **Electron native**: `webContents.printToPDF` → real PDF saved to Downloads
  2. **Browser popup**: `window.print()` dialog
  3. **Blob fallback**: HTML file download → open in browser → Ctrl+P

### 📊 Meeting Debt Tracking *(Supabase required)*
- Cross-meeting semantic search for unresolved action items
- Surfaces "meeting debt" from previous sessions using Gemini embeddings (`text-embedding-004`)

### 🖥️ Slide Context Engine *(Vision mode)*
- Perceptual hashing detects when a new slide appears on screen
- Gemini 1.5 Pro Vision analyzes the slide content and adds it to context

```
      ▼

```

## 🚀 Quick Start

### Prerequisites

| Requirement | Version | Notes |
|---|---|---|
| Python | 3.11+ | 3.13 supported |
| Node.js | 18+ | LTS recommended |
| Git | Any | |

### API Keys Required

| Service | Where to get it | Used for |
|---|---|---|
| **Google AI Studio** | [aistudio.google.com](https://aistudio.google.com/app/apikey) | Gemini 1.5 Flash (tasks) + Pro (debrief) |
| **Deepgram** | [console.deepgram.com](https://console.deepgram.com) | Nova-2 speech-to-text |
| **Supabase** *(optional)* | [supabase.com](https://supabase.com) | Meeting debt tracking |

### Installation

**Step 1 — Clone and install**
```bash
git clone https://github.com/your-org/meetintel.git
cd meetintel

# Auto-install everything (backend venv + frontend npm)
.\install.bat
```

**Step 2 — Configure environment**
```bash
# Copy and fill in the template
copy backend\.env.example backend\.env
notepad backend\.env
```

Fill in `backend/.env`:
```env
# Required
GOOGLE_API_KEY=AIza...           # From Google AI Studio
DEEPGRAM_API_KEY=...             # From Deepgram Console

# Optional (enables meeting debt tracking)
SUPABASE_URL=https://xxx.supabase.co
SUPABASE_SERVICE_KEY=eyJ...

# Optional (webhook integrations)
ZAPIER_WEBHOOK_URL=https://hooks.zapier.com/...
```

**Step 3 — Launch all three processes** *(in three separate terminals)*

```powershell
# Terminal 1: Backend
cd backend
.\venv\Scripts\activate
uvicorn main:app --reload

# Terminal 2: Renderer  
cd renderer
npm run dev

# Terminal 3: Electron
.\start_electron.bat
```

Or launch everything at once from the project root:
```powershell
npm run dev
```

## ⚙️ Configuration

All backend settings are managed in `backend/config.py` via Pydantic BaseSettings. Every value can be overridden with an environment variable in `backend/.env`.

| Setting | Default | Description |
|---|---|---|
| `GOOGLE_API_KEY` | — | Google AI Studio key (required) |
| `DEEPGRAM_API_KEY` | — | Deepgram key (required) |
| `GEMINI_TEXT_MODEL` | `gemini-1.5-flash` | Live task extraction model |
| `GEMINI_DEBRIEF_MODEL` | `gemini-1.5-pro` | Post-session summary model |
| `GEMINI_VISION_MODEL` | `gemini-1.5-pro` | Slide analysis model |
| `GEMINI_EMBED_MODEL` | `models/text-embedding-004` | Debt RAG embeddings |
| `ACTION_WINDOW_SIZE` | `20` | Sliding transcript window size |
| `ACTION_TRIGGER_INTERVAL` | `3` | Segments between action checks |
| `DEEPGRAM_MODEL` | `nova-2` | Deepgram STT model |
| `DEEPGRAM_LANGUAGE` | `en-US` | Transcription language |
| `DEEPGRAM_SAMPLE_RATE` | `16000` | Audio sample rate (Hz) |
| `SLIDE_CHANGE_THRESHOLD` | `0.15` | pHash distance for slide detection |
| `DEBT_SIMILARITY_THRESHOLD` | `0.78` | Cosine similarity floor for debt RAG |

| Endpoint | Method | Description |
|---|---|---|
| `/debrief/generate` | POST | Generate full post-meeting report |
| `/debt/query` | POST | Query cross-meeting debt items |
| `/vision/analyze` | POST | Analyze a screenshot for slide content |

### WebSocket

```
ws://127.0.0.1:8000/ws/transcribe
ws://127.0.0.1:8000/ws/audio      (alias)
```

**Inbound** (Electron → Backend): Raw binary Int16 PCM frames (16 kHz, mono)

**Outbound** (Backend → Electron): JSON messages

```json
// Transcript chunk
{ "type": "transcript", "transcript": "Parth, please update...", "speaker": "Speaker 1", "is_final": true }

// Action item detected
{ "type": "action_item", "id": "uuid", "title": "Update API documentation", "assignee": "Parth Bhad", "priority": "high", "context": "Parth, please update the API documentation by this Friday" }

// Speaker identity resolved
{ "type": "identity_update", "map": { "1": "Aaditya Hingmire", "2": "Parth Bhad" } }
```

### Session Start Payload

```json

  "title": "Product Sync — April 19",
  "admin": "Aaditya Hingmire",
  "participants": ["Parth Bhad", "Aryan Karpe", "Aaditya Hingmire"]
```

## 🧠 AI Engine Details

### ActionEngine (Gemini 1.5 Flash)
- **Trigger 1**: Every 3 final transcript segments
- **Trigger 2**: Immediately when a participant's first name is detected in a segment
- Uses a sliding window of the last 20 segments
- Prompt includes admin name, all participant names, and speaker-labeled transcript
- Returns structured JSON: `id, title, assignee, priority, context`
- Deduplication via seen-title set (prevents duplicate cards)

### DebriefEngine (Gemini 1.5 Pro)
- Runs on the **complete transcript** after session stop
- Returns: `summary, key_decisions, risks, next_steps, notes, action_items`
- Higher quality than Flash — uses `temperature: 0.3` for factual accuracy

### Identity Engine (Gemini 1.5 Flash)
- Runs every 5 final segments
- Infers speaker→name mapping from conversational context
- Maps `Speaker 0` → `Aaditya Hingmire`, `Speaker 1` → `Parth Bhad`, etc.
- Updates the live transcript display retroactively

## 🔒 Security

- **Context Isolation**: Renderer never gets direct Node.js access — all IPC via `contextBridge`
- **CSP**: `Content-Security-Policy` restricts connections to `localhost:3000` and `127.0.0.1:8000` only
- **Navigation Guard**: All external navigation blocked — only known safe origins allowed
- **Popup Control**: `setWindowOpenHandler` denies all new windows except blank-target PDF windows
- **No API Keys in Renderer**: All Deepgram/Gemini calls go through the Python backend — the renderer only touches `localhost`

## 🐛 Troubleshooting

### "Offline" status in the status bar
- Ensure FastAPI is running: `uvicorn main:app --reload` in `backend/`
- Ensure `DEEPGRAM_API_KEY` is set in `backend/.env`
- Check that the port `8000` is not in use: `netstat -ano | findstr 8000`

### Tasks not appearing in the Actions panel
1. Check backend logs for `[ActionEngine]` lines
2. Ensure you said participant names clearly: "**Parth**, please..."
3. If using diarization, identity mapping takes ~5 segments to build
4. After stopping the session, wait 2-3 seconds — the final sweep runs then

### PDF download not working
- **Electron**: A dialog prompts for the save location; the file opens automatically
- **Browser dev mode**: Popup blockers may prevent the print window — allow popups for `localhost:3000`
- **Fallback**: An `.html` file downloads — open it in Chrome and press `Ctrl+P` → `Save as PDF`

### `deepgram-sdk` import errors
The SDK is pinned to `>=3.2.7,<4.0.0` — v4+ has a completely different API. If you see import errors:
```bash
pip install "deepgram-sdk>=3.2.7,<4.0.0" --force-reinstall
```

### `GOOGLE_API_KEY` not found
```bash
# Verify .env is in the right place
ls backend/.env

# Test the key loads
cd backend && .\venv\Scripts\python.exe -c "from config import cfg; print(cfg.has_gemini)"
```
